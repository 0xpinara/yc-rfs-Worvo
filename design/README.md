# Worvo design sources

Lane C's original design exports. The site and app are built from these. They are references, not app code (ESLint ignores this folder).

| File | What it is | Built into |
| --- | --- | --- |
| [worvo-landing-page.html](worvo-landing-page.html) | The landing page design (self-unpacking export with its fonts). Open it in a browser. | `src/components/landing/` (page at `/`) |
| [tally-mascot/](tally-mascot/) | **Tally, the Worvo sea otter**: the main waving pose plus listening, writing it up, has a question and paid, with the colour palette. Open `Mascot.dc.html` from a local server (see its README). `preview.png` is a rendered snapshot. | `src/components/landing/tally/*.svg` (hero, demo badge, Tally tour, app) |
