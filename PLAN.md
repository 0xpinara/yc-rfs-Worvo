# Worvo plan

Build the smallest voice-to-invoice assistant for a solo plumber.

For the hackathon build, [AGENTS.md](AGENTS.md) is the scope: one demo path, no login or database, Stripe test mode. [docs/DEMO.md](docs/DEMO.md) has the demo utterance and the expected invoice.

The longer documents in `docs/` (implementation plan, parallel work plan, tasks, sources) describe the post-hackathon production version.
